# Implementation Plan: Vehicle Registry Fields (ANTT, Renavam, Chassi) + Form Layout

**Branch**: `023-vehicle-registry-fields` | **Date**: 2026-07-28 | **Spec**: [spec.md](./spec.md)

## Summary

Issue #30 [0007]: add ANTT (RNTRC), Renavam and Chassi to the vehicle registry and regroup the
form. Same contained pattern as slice 022 (driver CPF): shared Zod primitives (`renavamSchema`
strip→9–11 digits; `chassisSchema` uppercase/strip→17 VIN chars, no I/O/Q; ANTT plain
`optionalText(20)`), three nullable columns on `vehicles` (additive migration), service
DTO/insert/update field list, form + detail client, pt-BR catalog, PRD amendments. Layout:
Placa|Tipo, Renavam|ANTT, Chassi|Capacidade — Capacidade drops from full-width to a half cell.
